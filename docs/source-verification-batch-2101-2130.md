## Evidence basis

Documentation-level verification only. Official Bybit documentation was checked for Delivery Price, Delivery Record, WebSocket Ticker, Instruments Info, Tickers, and the V5 changelog. These records do not activate any provider or authorize any strategy input. Where an endpoint is account-authenticated, its documented semantics are recorded as documentation evidence only and are not treated as an approved unauthenticated production source.

## Reports

2101. Bybit Delivery Price returns a `category` field identifying the product type in the response.
2102. Bybit Delivery Price returns `symbol` for each delivery-price record.
2103. Bybit Delivery Price returns `deliveryPrice` as the documented delivery price value.
2104. Bybit Delivery Price returns `deliveryTime` as a delivery timestamp in milliseconds.
2105. Bybit Delivery Price supports `limit` from 1 to 200 and documents a default of 50 records per page.
2106. Bybit Delivery Price supports cursor pagination through `nextPageCursor`.
2107. Bybit Delivery Price supports `symbol` filtering and requires uppercase symbol format when supplied.
2108. Bybit Delivery Price supports `baseCoin` for Options and documents BTC as the default base coin when applicable.
2109. Bybit Delivery Price supports `settleCoin` filtering and documents USDC as the default settlement coin where applicable.
2110. Bybit Delivery Price covers USDT Futures, USDC Futures, Inverse Futures, and Options.
2111. Bybit Delivery Price documents that Options without a specified symbol return symbols in the `DELIVERING` state during the documented UTC 8–12 delivery window.
2112. Bybit Delivery Price warns that extreme market volatility can cause increased latency or temporary delays in data delivery.
2113. Bybit WebSocket Ticker documents `ts` as the timestamp in milliseconds generated by the system for the data message.
2114. Bybit WebSocket Ticker documents `type` as the data type and identifies the ticker message type as `snapshot`.
2115. Bybit WebSocket Ticker documents `cs` as a cross-sequence integer field.
2116. Bybit WebSocket Ticker includes `lastPrice` in ticker data as the latest price field.
2117. Bybit WebSocket Ticker includes `deliveryTime` for expiry futures and documents it as a UTC datetime field.
2118. Bybit WebSocket Ticker includes `predictedDeliveryPrice` and documents that it has a value 30 minutes before delivery.
2119. Bybit Instruments Info now documents that `baseCoin=All` can be used for Options to return all option symbols; the changelog records this update on 2026-09-10.
2120. Bybit Instruments Info documents `status` filtering and distinguishes states such as PreLaunch, Trading, Settling, Delivering, and Closed; a state must therefore be interpreted explicitly rather than inferred.
2121. Bybit Instruments Info documents `symbol` as uppercase-only when supplied.
2122. Bybit Instruments Info documents `baseCoin` as applicable to linear, inverse, and option categories.
2123. Bybit Instruments Info documents that Spot does not support pagination, making `limit` and `cursor` invalid for Spot.
2124. Bybit Instruments Info documents a default page size of 500 and a maximum of 1000 for the relevant paginated categories.
2125. Bybit Instruments Info warns that extreme market volatility can cause increased latency or temporary delays in data delivery.
2126. Bybit Instruments Info warns that `maxLimitOrderQty`, `maxMarketOrderQty`, and `postOnlyMaxLimitOrderSize` are adjusted bi-monthly and should not be assumed constant.
2127. Bybit Delivery Record is documented as an account/asset endpoint; its examples use API key and API secret authentication, so this endpoint is not treated as a keyless public market-data source for production activation.
2128. Bybit Delivery Record documents `deliveryTime` as milliseconds, `side` as Buy/Sell, and `position` as executed size.
2129. Bybit Delivery Record documents `entryPrice` as average entry price, `deliveryPrice` as delivery price, `strike` as exercise price, `fee` as trading fee, and `deliveryRpl` as realized PnL of the delivery.
2130. Bybit Delivery Record limits each request to a maximum 30-day time range when both `startTime` and `endTime` are supplied, supports cursor pagination, and warns of possible latency or temporary delivery delays during extreme volatility.

## Authorization boundary

None of these records authorizes a LONG/SHORT rule. No threshold, score, signal rule, provider activation, execution path, order endpoint, private credential, or automatic trading capability is added. Delivery Record is explicitly not activated as a keyless public source because the official documentation demonstrates authenticated access. PIT, provenance, validation, allowed-consumer, and Strategy Contract requirements remain mandatory.
