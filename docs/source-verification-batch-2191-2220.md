## Reports

2191. Bybit `Get Orderbook` uses the public HTTP endpoint `/v5/market/orderbook`.
2192. Bybit `Get Orderbook` covers Spot, USDT contract, USDC contract, Inverse contract, and Option products.
2193. Bybit `Get Orderbook` requires `category`, with values `spot`, `linear`, `inverse`, and `option`.
2194. Bybit `Get Orderbook` requires the symbol in uppercase form.
2195. Bybit `Get Orderbook` documents 1–1000 levels for Spot and contract categories, and 1–25 levels for Options.
2196. Bybit states that the Orderbook response is in snapshot format.
2197. In the Orderbook response, bids are sorted by price in descending order.
2198. In the Orderbook response, asks are sorted by price in ascending order.
2199. The Orderbook `ts` field is the millisecond timestamp generated by the Bybit system.
2200. The Orderbook `cts` field is the matching-engine production timestamp and can be correlated with the `T` field from the public trade channel.
2201. Bybit `Get Index Price Kline` uses `/v5/market/index-price-kline` for historical index-price klines.
2202. Bybit documents Index Price Kline for linear and inverse categories, with linear as the default when `category` is omitted.
2203. Index Price Kline requires an uppercase symbol.
2204. Index Price Kline requires an `interval` and documents `1,3,5,15,30,60,120,240,360,720,D,W,M`.
2205. Index Price Kline supports optional `start` and `end` timestamps in milliseconds.
2206. Index Price Kline documents a page `limit` from 1 to 1000 with a default of 200.
2207. Index Price Kline responses contain candle arrays sorted in reverse by `startTime`.
2208. Bybit states that Index Price Kline `closePrice` is the last traded price when the candle is not closed.
2209. Bybit `Get Mark Price Kline` uses `/v5/market/mark-price-kline` for historical mark-price klines.
2210. Mark Price Kline documents `linear`, `inverse`, and `option` categories, with linear as the default when `category` is omitted.
2211. Mark Price Kline requires an uppercase symbol.
2212. Mark Price Kline requires an `interval` and documents `1,3,5,15,30,60,120,240,360,720,D,M,W`.
2213. Mark Price Kline supports optional `start` and `end` timestamps in milliseconds.
2214. Mark Price Kline documents a default `limit` of 200, with futures limits 1–1000 and option limits 1–500.
2215. Mark Price Kline responses contain candle arrays sorted in reverse by `startTime`.
2216. Mark Price Kline `closePrice` is documented as the last traded price when the candle is not closed.
2217. Bybit `Get Premium Index Price Kline` uses `/v5/market/premium-index-price-kline`.
2218. Premium Index Price Kline covers USDT and USDC perpetual products and documents `category=linear`.
2219. Premium Index Price Kline requires an uppercase symbol and documents intervals `1,3,5,15,30,60,120,240,360,720,D,W,M`.
2220. Premium Index Price Kline documents `limit` from 1 to 1000 with a default of 200 and returns candle arrays in reverse order by start time.
