# Telegram notification settings

این سند فقط قرارداد تنظیمات اعلان سیگنال است. این پروژه هیچ سفارش، معامله یا اجرای مستقیم روی صرافی انجام نمی‌دهد.

## متغیرهای محیطی

| متغیر | الزامی | پیش‌فرض | توضیح |
|---|---:|---:|---|
| `TELEGRAM_BOT_TOKEN` | بله | — | توکن ربات؛ فقط از Secret یا environment امن تأمین شود. |
| `TELEGRAM_CHAT_ID` | بله | — | شناسهٔ مقصد اعلان، به‌صورت رشته. |
| `TELEGRAM_ENABLED` | خیر | `false` | مقادیر مجاز: `true/false`، `1/0` یا `yes/no`. |
| `TELEGRAM_TIMEOUT_SECONDS` | خیر | `10` | timeout مثبت برای لایهٔ ارسال آینده. |
| `TELEGRAM_MAX_ATTEMPTS` | خیر | `3` | سقف تلاش برای لایهٔ ارسال آینده؛ حداقل `1`. |

## الزامات امنیتی

- توکن نباید در کد، commit، issue، log یا پیام خطا ثبت شود.
- `redacted()` فقط وضعیت پیکربندی را برای diagnostics برمی‌گرداند و توکن را افشا نمی‌کند.
- فعال‌کردن تنظیمات به‌تنهایی هیچ پیام واقعی ارسال نمی‌کند.
- ارسال آینده باید فقط رویدادهای اعلان سیگنال را از outbox مصرف کند؛ `BLOCKED` نباید اعلان شود.
- اتصال واقعی Telegram، retry عملیاتی، dead-letter و recovery هنوز جداگانه باید پیاده‌سازی و آزمون شوند.
